# 🔮 LLM 划词翻译 (LLM Selection Translator)

一个轻量级、现代化的浏览器划词翻译扩展，支持多种大语言模型（LLM）和传统翻译引擎。特别针对 OpenAI 格式的大模型 API（如 DeepSeek、Moonshot、Qwen、GLM 等）进行了流式输出和思考过程展示的深度优化。

无论是阅读外文文献、浏览网页，还是应对长篇的 PDF 文件，**LLM 划词翻译** 都能为您带来流畅、准确且高度可定制的翻译体验。

---

## ✨ 核心特性

- **🖱️ 划词即译**
    - 在网页任意位置选中文字，即刻唤起翻译悬浮按钮，支持流畅的打字机般流式输出展示。
    - 智能的源语言自动识别能力，支持中英双向智能互译。
- **📄 原生 PDF 划词翻译支持**
    - 内置针对扩展优化的 PDF.js 阅读器。无论是在线 PDF 还是本地 PDF，都能像普通网页一样使用无缝的划词翻译体验。
- **🧠 强大的推理想法（Chain of Thought）展示**
    - 原生支持深度思考模型（如 DeepSeek-R1 等）。
    - 可视化、可折叠的“思考过程”展示窗口，不仅知道译文，更懂模型背后的翻译逻辑与推导思路。
- **🤖 全面的多引擎支持**
    - **OpenAI 兼容及各家大模型（推荐）**：支持 OpenAI、Claude、Gemini、DeepSeek、Qwen（通义千问）、GLM（智谱）、xAI Grok、Moonshot、小米云大模型等。
    - **Ollama（本地化首选）**：全自动探测本地运行的模型，支持思考流展示，让私有化部署无缝接入您的浏览器。
    - **WebLLM（浏览器端侧 AI）**：基于 WebGPU 的纯前端端侧模型运行，保障绝对的隐私。
    - **浏览器原生 AI API（前沿实验）**：支持调用新版 Chrome 内置的 Translation API 和 LanguageDetector API 进行脱机极速翻译。
    - **传统机器翻译**：内置 Google 翻译与 Bing 翻译，提供稳定保底支持。
- **☁️ 跨设备数据同步与术语库管理**
    - 支持 **WebDAV 多端跨设备双向同步**。
    - 支持快捷的配置、术语库本地 JSON 文件的导入导出。
    - 内置专属“术语库”支持，确保垂直领域的专有名词翻译一致性。
- **🎨 现代、沉浸式的 UI 体验**
    - 精美的卡片式弹窗交互设计。
    - 自适应暗黑/明亮夜间模式（根据系统主题或网页自动适配）。

## 🚀 安装指南

由于本扩展处于快速迭代的开发者预览版阶段，请按照以下步骤手动加载扩展程序：

### 下载扩展包

前往项目的 [Releases 页面](../../releases) 下载最新版本的压缩包（\.zip\ 或 \.xpi\）。

### Chrome / Edge (Chromium 内核浏览器)

1. 下载最新的 \.zip\ 压缩包并将其解压至本地文件夹。
2. 在浏览器地址栏输入扩展管理页地址打开：
    - **Chrome**: \chrome://extensions\
    - **Edge**: \edge://extensions\
3. 开启页面右上角的 **"开发者模式" (Developer mode)**。
4. 点击 **"加载已解压的扩展程序" (Load unpacked)**。
5. 选择您在第 1 步中解压得到的文件夹即可安装成功，建议将扩展图标固定在工具栏以便随时设置。

### Firefox 浏览器

1. 下载最新的 \.xpi\ 安装包。
2. 在 Firefox 地址栏输入 \bbout:addons\。
3. 点击页面右上角的齿轮图标 ⚙️，然后选择 **"从文件安装附加组件" (Install Add-on From File)**。
4. 选取下载的 \.xpi\ 文件。
5. _注意：若为您未签名的开发版扩展，可能需要在 Firefox Developer Edition / Nightly 版本中，或通过 \about:debugging\ 的“临时加载附加组件”模式载入。_

## ⚙️ 核心功能配置

点击浏览器右上角的扩展图标，即可进入现代化的**后台设置页面**：

### 1. 基础大模型配置（以 DeepSeek/OpenAI 为例）

- **API 地址**: 填入 OpenAI 官方或兼容 API 的地址（例如 \https://api.openai.com/v1\ 或 \https://api.deepseek.com/v1\）。
- **API Key**: 填入您申请的 API 密钥 (\sk-...\)。
- **主要翻译模型**: 用于常规翻译的模型，如 \gpt-4o-mini\, \deepseek-chat\。
- **深度思考开关**: 若您的模型支持推理/思考逻辑（如 \deepseek-reasoner\），启用“显示思考过程”选项后，弹窗中将渲染出可折叠的思考过程框。

### 2. 本地私有化模型 (Ollama)

- **默认服务地址**: 默认为 \http://localhost:11434/api/chat\。您可以根据实际部署端口修改。
- **模型一键探测**: 设置页面会自动请求本地服务并列出可用模型。只需从下拉菜单选择即可使用。
- **本地思考支持**: 通过简单切换开关即可向 Ollama 传递触发思路生成的特定参数限制（如发送 \ hink\ 参数）。

### 3. WebGPU 浏览器侧模型 (WebLLM)

- Chrome / Edge 用户可利用本地显卡的算力，将小参数量的大语言模型直接下载并运行于浏览器后台中。
- 提供内置模型推荐列表，首次翻译时自带下载进度加载条栏目。开启闲置超时回收机制，不产生多余的后台负载。

### 4. 数据的高级管理 (WebDAV / JSON)

- **多设备同步**: 设置正确的 WebDAV 地址、账号密码后，可以进行“单向上传”、“单向下载” 或启用 “智能双向检测合并规则”，保证多台设备上的术语与配置保持一致。
- **本地备份**: 支持将现存的“扩展配置”和“专属术语表”分离为独立的 JSON 文件离线下载与恢复。

## 📖 日常使用与进阶玩法

1. **网页畅游翻译**：
   直接用鼠标拖蓝选中网页文字，右下方即时浮现“翻译按钮”。点击它，即可在精美的视窗中查看大模型逐字给出的信达雅译文。
2. **轻便结束查阅**：
   单击弹窗右上角的 \×\ 或鼠标点击网页的任意其他空白处即可瞬间收起。
3. **沉浸式 PDF 阅读**：
    - 只要点击或访问以 \.pdf\ 结尾的网络链接（\http/https\），扩展会自动拦截并使用内置的轻量 PDF 阅读器渲染它，带来和普通网页一样的完美划词翻译体验。
    - **对于本地 PDF 文件阅读**：点击扩展栏的插件图标进入设置页，点击 **“打开本地 PDF（Firefox 兼容）”** 按钮。在弹出的新版阅读器中通过文件选择器加载本地文件即可安心阅读翻译。

## 🛠️ 常见问题 (FAQ)

- **Q: 为什么划词后点击大模型翻译一直没有反应，或者加载很久？**
    - **A**: 检查您的 API Key 与接口地址（Endpoint）是否正确无误；其次确认您调用的 API 服务提供商是否允许**浏览器跨域请求 (CORS)**。部分官方端点若不允许 CORS 可以寻找反向代理地址替代。
- **Q: 模型明明支持思考，为什么弹窗没有显示“思考过程”面板？**
    - **A**: 请在设置页面核实是否勾选了**【显示思考过程】**选项；注意只有 API 的服务端返回特定的字段结构（如 DeepSeek 的 \
      easoning_content\）才能被正确拦截提取展示。
- **Q: WebLLM 模式提示因检测不通过被禁用？**
    - **A**: 该模式要求浏览器需开启并支持 WebGPU 接口，如果您的显卡过于老旧或驱动受限，浏览器会硬件降级不支持该功能。此时建议您退换使用云端大模型方案。

## 📜 开发者指南

_如果你有意进行二次修改或对源码感兴趣：_

- **\manifest.json**: Chrome Extension MV3 核心配置文件。
- **\content_script.js**: 控制页面高亮渲染、划词事件监听、弹窗 UI 管理以及流式消息的 DOM 拼装。
- **\background 目录**: 整个翻译流程的后方调度中枢（Service Worker），负责各家 LLM 请求适配封装及 WebDAV 远端网络同步任务等。
- **\vendor**: 集成的 PDF.js 等相关核心第三方依赖，用于提供脱离原生的统一 PDF 文档解析界面。
- **\options**: 用户交互式偏好配置大本营逻辑（依靠 \chrome.storage.sync/local\ 分割存储策略）。
- 本项目不依赖繁琐的前端框架脚手架（如 React/Vue 打包），保持了用原生代码即改即看、易于 Hack 的最轻量级拓展设计思想。
