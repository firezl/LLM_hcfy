快速上手

按设置页里的真实引擎完成配置

先在“通用”里选择首选翻译引擎。如果选择“大模型翻译”，再到“引擎”里选择具体模型来源。 API Key 会保存在本地浏览器存储中，不会通过 WebDAV 配置同步上传。

打开设置

先选哪一个

1

想最快试用

选择“OpenRouter”，申请 Key 后保留默认模型 openrouter/free。免费模型有额度和稳定性限制。

2

想要本地隐私

选择“Ollama 本地服务”，先安装 Ollama 并拉取模型，再回到设置页选择检测到的模型。

3

想要稳定质量

选择 OpenAI、Gemini、Claude、DeepSeek、Qwen、GLM、xAI Grok 或 Xiaomi MiMo，按平台申请 Key。

通用引擎

自动

auto

设置页默认项。当前路由会走 OpenAI 适配，因此仍需要配置 OpenAI API 地址、Key 和模型。

  • 适合：只想保持默认行为。
  • 设置：通用 -> 首选翻译引擎 -> 自动。

大模型翻译

llm

这是所有 LLM 提供方的总入口。选择后，在“引擎”页的“大模型提供方”里选择 OpenAI、OpenRouter、Ollama 等具体引擎。

  • 适合：需要术语、Prompt、思考过程或更自然译文。
  • 设置：通用 -> 大模型翻译；引擎 -> 大模型提供方。

专用大模型翻译

special_translate

面向 Translationgemma 这类专用翻译模型。默认 provider 是 Ollama，也可以切换到 OpenAI 兼容服务。

http://localhost:11434/api/chat
  • provider 选 Ollama：通常不需要 API Key。
  • provider 选 OpenAI 兼容：按服务要求填写 Key，可留空给本地服务。
  • 模型默认：translategemma。

Google 翻译

google

传统机器翻译入口，不需要在设置页填写 API Key。适合做轻量兜底。

  • 适合：快速、免费、对质量要求不高的网页阅读。
  • 设置：通用 -> 首选翻译引擎 -> 谷歌翻译。

Bing 翻译

bing

传统机器翻译入口，不需要在设置页填写 API Key。可作为 Google 翻译不可用时的备用选择。

  • 适合：不想申请 API Key 的用户。
  • 设置：通用 -> 首选翻译引擎 -> Bing翻译。

浏览器 AI

browser

实验入口，面向最新版 Chrome / Edge 的浏览器内置 Translation API。翻译在网页划词时于页面内完成，不经过扩展后台；Firefox 不支持，PDF 阅读器内请改用其他引擎。

  • 适合：离线/低延迟的简单网页翻译。
  • 复杂推理或 PDF：请使用大模型翻译或 Ollama。

本地 OpenAI 兼容服务

这些工具通常可以通过“自定义 OpenAI 兼容”接入。因为当前设置页会要求 API Key，本地服务没有 Key 时可先填 local，如果服务拒绝 Authorization 头，再改用支持可选 Key 的“专用大模型翻译 -> OpenAI 兼容”路径。

工具 常见 API 地址 备注
LM Studio http://localhost:1234/v1/chat/completions 在 LM Studio 中启动 Local Server 后使用。
llama.cpp server http://localhost:8080/v1/chat/completions 端口取决于启动参数。
LocalAI / New API / One API http://localhost:8080/v1/chat/completions 以实际部署地址和模型名为准。

字段怎么填

  • API 地址可以填完整接口，也可以填基础路径；插件会对 OpenAI 兼容地址补全 /chat/completions。
  • 模型下拉里没有想用的模型时，选择“自定义模型名”，再填写平台给出的模型 ID。
  • Prompt 支持 {targetLang}、{text}、{glossary}、{glossaryConstraint}。
  • 思考过程只在模型和平台返回对应字段时显示；打开开关不代表所有模型都会返回思考内容。
  • 保存设置后，刷新正在阅读的网页，再重新划词测试。

常见问题

  • 提示缺少 Key：确认当前“通用”里的首选引擎和“引擎”里的大模型提供方一致。
  • 本地服务连不上：确认 Ollama、LM Studio 或其他服务正在运行，且地址使用 localhost 或 127.0.0.1。
  • 模型列表为空：先手动填自定义模型名；有些平台模型列表接口需要额外权限或暂时不可用。
  • OpenRouter 免费模型失败：免费模型有频率、日额度和可用性限制，可换一个 :free 模型或改用付费模型。
  • 浏览器 AI 不工作：确认使用 Chrome/Edge 最新版、已在网页（非 PDF 阅读器）划词，且浏览器已允许 Translation API；否则改用大模型翻译。
