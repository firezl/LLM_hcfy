字段怎么填

  • API 地址可以填完整接口，也可以填基础路径；插件会对 OpenAI 兼容地址补全 /chat/completions。
  • 模型下拉里没有想用的模型时，选择“自定义模型名”，再填写平台给出的模型 ID。
  • Prompt 支持 {targetLang}、{text}、{glossary}、{glossaryConstraint}、{selected_text}、{before_context}、{after_context}、{block_text}、{page_title}、{page_domain}、{page_lang}、{context}。上下文占位符仅在大模型引擎且智能上下文翻译未关闭时有效。
  • 思考过程只在模型和平台返回对应字段时显示；打开开关不代表所有模型都会返回思考内容。
  • 保存设置后，刷新正在阅读的网页，再重新划词测试。

常见问题

  • 提示缺少 Key：确认当前“通用”里的首选引擎和“引擎”里的大模型提供方一致。
  • 本地服务连不上：确认 Ollama、LM Studio 或其他服务正在运行，且地址使用 localhost 或 127.0.0.1。
  • 模型列表为空：先手动填自定义模型名；有些平台模型列表接口需要额外权限或暂时不可用。
  • OpenRouter 免费模型失败：免费模型有频率、日额度和可用性限制，可换一个 :free 模型或改用付费模型。
  • 浏览器 AI 不工作：确认使用 Chrome/Edge 最新版、已在网页（非 PDF 阅读器）划词，且浏览器已允许 Translation API；否则改用大模型翻译。
